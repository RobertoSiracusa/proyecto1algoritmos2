1. **🏗️ Inicialización** (2 min)

   - Crea red base
   - Inicializa componentes

   - Router, Switch, PCs
   - Configuración IP/MAC
   - Estados online

3. **🔗 Conexiones** (2 min)
   - Topología de red
   - Enlaces físicos
   - Verificación

4. **📊 Comandos Show** (3 min)
   - `show devices`
   - `show interfaces`
   - `show statistics`

5. **📡 Paquetes** (4 min)
   - Envío automático
   - Procesamiento tick
   - Routing

6. **📈 Estadísticas** (2 min)
   - Métricas de red
   - Top talkers
   - Reportes

7. **💾 Persistencia** (2 min)
   - Guardar JSON
   - Metadatos
   - Configuración

8. **🎮 CLI** (1 min)
   - Modos CLI
   - Comandos config
   - Navegación

9. **🎉 Resumen** (1 min)

   - Métricas finales
